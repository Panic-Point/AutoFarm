# Art credits

The farm is drawn with Liberated Pixel Cup (LPC) style art from
[OpenGameArt](https://opengameart.org). These licenses let the art be shared
in a public project like this one, as long as the authors are credited (and,
for CC-BY-SA art, changed versions are shared under the same license). Bolt,
the hats, sunflowers, mushrooms, the well and the bee hive are drawn in code in
`js/render.js`.

The game recolors some sheets as it draws them (watered soil, wilted and
rotten crops) and trims each soil, wheat and grass tile to a rounded square.
